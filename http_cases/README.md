# http_cases

Dependency-free annotations for grouping user-written HTTP test cases into a
strongly typed catalog generated by `http_cases_generator` and `craft_runner`.

```dart
import 'package:http_cases/http_cases.dart';

@ApiCase('cart')
class GetV1 {
  const GetV1();

  @DefaultCase()
  void success() {}

  void failed() {}
}
```

The generator exposes the class as `apiCases.cart.getV1` and includes
`success()` in `apiCases.setUpDefaults()`.

`http_cases` has no runtime dependencies. Add `http_cases_generator` and
`craft_runner` as development dependencies to generate the catalog.
